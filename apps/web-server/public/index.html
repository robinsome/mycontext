客户端采集（调试/应急 · 会话/消息）

非主路径：仅当上方「运行采集」无法满足（调试、断 sidecar、应急补数）时使用。 本机需 Node.js + 全局 dws@1.0.60（dws auth login）+ 下方脚本；服务器不替你跑 dws。请先扫码登录再下载（脚本写入 Sync URL / Token / Vault ID）。

  1. 安装 Node LTS → npm install -g dingtalk-workspace-cli@1.0.60
  2. 本机执行 dws auth login
  3. 下载 TypeScript 脚本 → npx --yes tsx ./mycontext-collect-from-dws.ts
  4. 回到本页「同步状态」确认已推送
